<h2>6.3 Профили. Условная настройка и создание компонентов</h2>
<ul>
	<li>
		В одном <b>application.yaml</b> можно задавать настройки для разных профилей, разделяя их тройным дефисом: ---
	</li>
	<li>
		Настройка создания бинов под конкретный профиль: (после аннотации <b>@Bean</b> пишем <b>@Profile(перечисление профилей)</b>
		<b>
		<ul>
			<li>
				@Profile("dev")
			</li>
			<li>
				@Profile({"dev", "qa"})
			</li>
			<li>	
				@Profile("!prod")
			</li>
			<li>
				@Profile({"!prod", "!qa"})
			</li>
		</ul>
		</b>
	</li>
</ul>
