<h2>6.1 Настройка автоконфигурации</h2>
<ul>
	<li>
		Окружение Spring поддерживает несколько источников свойств, в том числе:
		<ul>
			<li>
				Системные свойства JVM;
			</li>
			<li>
				Переменные окружения операционной системы;
			</li>
			<li>
				Аргументы командной строки;
			</li>
			<li>
				Файлы конфигурационных свойств приложения;
			</li>
		</ul>
	</li>
	<li>
		Вместо строки <b>server.port=9090</b> в <b>application.properties/yaml</b> можно написать в командной строке:<br />
		<b>$ java -jar tacocloud-0.0.5-SNAPSHOT.jar --server.port=9090</b><br />
		Либо внести в переменную окружения: <b>$ export SERVER_PORT=9090</b>. В этом случае Spring сам интерпретирует <b>SERVER_PORT</b> в <b>server.port</b>
	</li>
	<li>
		Настроим application-prod.properties для доступа к БД.
	</li>
	<li>
		Так же вместо явной конфигурации источника данных моно указать службу имён и каталогов Java <b>JNDI (Java Naming and Directory Interface)</b>
	</li>
	<li>
		Что-то говорится про <b>https</b>, но пока не понятно. Оставлю напотом.
	</li>
	<li>
		Для того, чтобы более аккуратно и читабельно выводить <b>логи</b>, создадим файл <b>logback.xml</b> в <b>src/main/resources</b>
	</li>
</ul>
