<h2>6.2 Создание своих конфигурационных свойств</h2>
<ul>
	<li>
		Добавим метод для поиска всех заказов одного пользователя: <b>OrdersForUser(User, Model)</b>;
	</li>
	<li>
		В этом методе будем применять новый элемент - <b>Pageable</b> для указания страниц, чтобы ограничить список;
	</li>
	<li>
		Для того, чтобы иметь возможность <b>задавать</b> возможность выбирать номер и размер списка полученных результатов, добавим аннотацию <b>@ConfigurationProperties(prefix="taco.orders")</b> к контроллеру <b>OrderController</b>, а так же новое свойство - <b>pageSize</b>.<br>
		Теперь мы имеем свойство <b>taco.orders.pageSize</b>, которое можем задавать в настройках. Например: <b>$ export TACO_ORDERS_PAGESIZE=10</b>;
	</li>
	<li>
		Другой, более правильный вариант - создать отдельный класс свойств и на него навесить аннотацию <b>@ConfigurationProperties</b>. Поэтому создадим класс <b>OrderProps</b> и в него зададим настройки;
	</li>
	<li>
		Чтобы создать <b>описание</b> для этого свойства, нам необходимо создать метаданные в <b>/src/main/resources/META-INF/additional-spring-configuration-metadta.json</b>
	</li>
</ul>
