<h2>7.2 Включение услуг на основе данных</h2>
<ul>
	<li>
		Добавим зависимость <b>spring-boot-starter-data-rest</b>
	</li>
	<li>
		Удалим все классы с аннотацией <b>@RestController</b>
	</li>
	<li>
		Для того, чтобы пути не конфликтовали с базовыми контроллерными путями, добавим в конфиг базовый путь (например data-api): spring.data.rest.pase-path="data-api"
	</li>
	<li>
		Для того, чтобы узнать, какие пути существуют, следует выполнить запрос к <b>localhost:8080/api</b>
	</li>
</ul>
